# Typography Component

Text primitive with 11 variants, color aliases, and weight overrides.

## Variants

| Variant | Size | Usage |
|---------|------|-------|
| `hero` | 32px | Hero titles |
| `h1` | 28px | Screen titles |
| `h2` | 24px | Section headers |
| `h3` | 20px | Sub-sections |
| `h4` | 18px | Card titles |
| `bodyLarge` | — | Emphasized body |
| `body` | 16px | Primary reading text |
| `bodySmall` | — | Secondary text |
| `caption` | 13px | Labels, hints |
| `captionSmall` | — | Fine print |
| `overline` | 11px | Uppercase labels |

## Props

- `variant` — see above
- `color` — theme color alias
- `weight` — `regular` | `medium` | `semibold` | `bold`
