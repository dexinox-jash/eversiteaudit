# Haptics Service

Tactile feedback wrappers around `expo-haptics`.

## Functions

| Function | Style |
|----------|-------|
| `hapticLight()` | `ImpactFeedbackStyle.Light` |
| `hapticMedium()` | `ImpactFeedbackStyle.Medium` |
| `hapticHeavy()` | `ImpactFeedbackStyle.Heavy` |
| `hapticSuccess()` | `NotificationFeedbackType.Success` |
| `hapticError()` | `NotificationFeedbackType.Error` |
| `hapticWarning()` | `NotificationFeedbackType.Warning` |

## Consumers

Camera, New Project, New Issue, Edit Issue, Project Detail, Templates, Export, Migration, Photo Viewer.
