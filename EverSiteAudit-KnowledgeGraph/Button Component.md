# Button Component

Pressable button with variants, sizes, haptic feedback, loading/disabled states.

## Variants

- `primary`
- `secondary`
- `destructive`
- `ghost`
- `outline`

## Sizes

- `default`
- `small`
- `icon`

## Props

- `variant`, `size`
- `loading`, `disabled`
- `fullWidth`
- `haptic` — default true
