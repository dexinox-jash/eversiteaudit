# Design System

> **Authority:** Child of `master.md`. Overrides nothing.

---

## Philosophy

- **Rugged Reliability** — "Construction-grade" design: professional, durable, trustworthy.
- **Offline-First** — Immediate local feedback, no loading spinners for local ops.
- **Sunlight-Optimized** — Dark mode default, minimum 4.5:1 contrast ratio.
- **Thumb-Friendly** — Primary actions in bottom 40%, 56dp touch targets.
- **Fail-Safe** — Destructive actions show counts, undo for 5s, auto-save forms.

- Blueprints → Planning/Structure

- Warning tape → Alerts/Severities
