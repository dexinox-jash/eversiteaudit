# Store Screenshot Guide

Capture the following screens for App Store and Google Play submission. Use clean device frames and ensure the app is set to light mode or the system appearance matches the brand (background color `#faf9f5`).

## Required Screens

1. **Gallery / Home**
   - Route: `(tabs)/gallery` or `(tabs)/index`
   - Show a populated gallery or project dashboard with sample data.
   - Highlight the clean card layout and navigation tabs.

2. **Issue Detail**
   - Route: `issues/[id]`
   - Open an existing issue with title, description, severity/status badges, and attached photos.
   - Demonstrate rich issue tracking capabilities.

3. **Export / PDF Preview**
   - Route: `export/index`
   - Display the export screen with a preview of a generated PDF report.
   - Show available share or download actions.

4. **Camera**
   - Route: `camera`
   - Show the native camera capture interface within the app.
   - Optional: include a captured image with annotation overlay.

5. **Photo Annotation**
   - Route: `photos/annotate/[id]`
   - Display a photo with markup drawn on it (arrows, circles, text).
   - Highlights field-ready photo documentation.

## Recommended Devices

- **iOS:** iPhone 15 Pro Max (6.7"), iPhone 15 Pro (6.1"), iPad Pro 12.9"
- **Android:** Pixel 8 Pro, Samsung Galaxy S24 Ultra, Pixel Tablet

## Tips

- Use realistic sample data (construction / facilities themes).
- Keep status bars clean (full battery, standard time, no low-signal warnings).
- Avoid showing personal or sensitive information.
- Match the app's `backgroundColor` (#faf9f5) in any empty canvas areas.
